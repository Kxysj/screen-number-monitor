# 屏幕数值监控 / Screen Number Monitor

Windows 屏幕区域数字 OCR 监控工具。像截图一样框选数字，为每个区域设置报警条件，通过电脑声音、Windows 系统通知或 Bark 通知提醒。

## 功能

- 拖动框选固定屏幕区域，可选跟随目标窗口移动。
- 创建多个监控，分别配置检测间隔、阈值和提醒方式。
- 支持大于、小于、区间内、区间外，以及数值持续不变、文字持续不变六种报警条件。
- 支持连续命中确认、报警冷却及持续异常重复提醒。
- 电脑报警音、Windows 系统通知与 Bark 推送可独立启用。
- 报警音已嵌入程序，Release 中的单个 EXE 可直接运行。
- 使用 Windows 本地 OCR，不上传截图。
- 黑白增强、实际小数点位置校正、负号保留及多次识别结果检查。
- 配置自动保存；Bark 地址使用 Windows DPAPI 加密。

## 环境

Windows 10 / 11 64 位，.NET Framework 4.8，以及 Windows 中文或英文 OCR 语言包。

不需要 Python 或第三方 OCR 服务。Python 脚本仅用于可选的报警音重新生成。

## 构建和运行

在项目目录打开 PowerShell，运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
.\dist\ScreenWatch.exe
```

构建脚本使用 Windows 系统 C# 编译器和 Windows 元数据，结果放在 `dist`。请保留整个目录，放在可写位置运行。

1. 打开需要监控的软件，使目标数字保持可见。
2. 点击“新建监控”，拖动框选数字区域，松开鼠标完成。
3. 点击“试识别”，核对取到的数值，再设置阈值和提醒方式。
4. 使用 Bark 时，在“Bark 设置”中填写自己的 `https://api.day.app/你的设备Key`。
5. 保存监控，点击“开始全部”。

## Windows 系统通知

在“新建监控”或“编辑选中”的“报警方式”中勾选“Windows 系统通知”。可以单独使用，无需配置 Bark。旧监控升级后默认不勾选此项，可按需开启。

报警时通过 Windows 通知区域显示监控名称、当前值、触发条件及时间，共用连续命中、冷却和重复提醒设置。点击通知或双击托盘图标可返回主窗口；窗口最小化时也可以请求通知，退出软件后监控停止。

点击主界面的“测试系统通知”可检查效果。通知的显示、停留时间和系统提示音由 Windows 管理，可能受系统通知设置、勿扰模式（专注助手）影响；关闭“电脑发出报警声”只关闭软件的报警音。事件记录中的“已请求”表示已调用系统通知接口，不代表用户已经看到通知。

可打开 [演示页面](examples/demo.html)，手动调节数值或开启自动变化，验证监控行为。

## 报警条件

| 条件 | 行为 |
| --- | --- |
| 大于上限 | 数值 > 上限 |
| 小于下限 | 数值 < 下限 |
| 超出区间 | 数值 < 下限，或数值 > 上限 |
| 进入区间 | 下限 ≤ 数值 ≤ 上限 |
| 数值持续不变 | 识别到的数值持续相同，达到指定秒数 |
| 文字持续不变 | 识别到的文字持续相同，达到指定秒数 |

默认每 2 秒检测、连续命中 2 次、冷却 60 秒。默认每轮异常提醒一次，读到正常值后重新布防；可开启重复提醒。多区域顺序识别，实际检测间隔受 OCR 耗时影响。

### 内容持续不变报警

在监控设置的“报警条件”中选择“数值持续不变”或“文字持续不变”，再填写“不变时长（秒）”（1～86400 秒，默认 60 秒）。例如设置 30 秒：首次成功识别开始计时，后续成功识别到同一内容持续满 30 秒时报警。主界面会显示已保持不变的时长。

- 数值模式按解析后的数值比较，`8` 和 `8.00` 视为相同，沿用数字序号和数字格式设置。
- 文字模式可识别中文、英文、数字和混合文字，不要求存在数字。比较时去掉首尾空白，把连续空白或换行合并成一个空格，保留大小写、标点和数字格式差异。
- 内容变化、识别失败、暂停或长时间采样中断后重新计时；空白区域视为识别失败。采样间隔超过“30 秒”与“检测间隔的 3 倍”中的较大值时，按中断处理。
- 不变条件不使用“连续命中次数”；达到时长后，在下一次成功检测时判断报警。检测间隔和 OCR 耗时决定实际提醒延迟，建议检测间隔小于不变时长。检测间隙内发生又恢复的变化无法被发现。
- 默认同一轮不变仅提醒一次；内容变化后重新布防。也可开启重复提醒，继续遵守报警冷却时间。声音、系统通知和 Bark 均可使用。
- “试识别”只检查识别结果，计时从“开始全部”后的首次成功检测开始。

数字序号 `0` 要求只有一个数字；`1`、`2` 等按 OCR 阅读顺序取值。百分数按显示数字比较，`12.5%` 作为 `12.5`。默认小数点格式 `1,234.56`，也可选择小数逗号格式 `1.234,56`。

## 配置与隐私

- 第一次启动没有预设监控和 Bark Key。请填写自己的地址。
- 本地 `settings.xml` 保存监控配置及加密后的 Bark Key，`settings.xml.bak` 为备份。这些文件已被 Git 忽略，请勿提交。
- 加密设置仅供当前 Windows 账户使用，换电脑或账户后应重新填写 Bark 地址。
- Bark 收到的是监控名称、当前数值、报警条件与时间，不包含截图。
- “测试推送”会真实发送 Bark 通知；“测试声音”会播放报警音；“测试系统通知”会请求 Windows 显示本机通知。
- 服务器确认接收不代表手机已经显示；网络错误会在事件记录中提示。

## 使用限制

目标区域必须可见。本工具不支持隐藏窗口、锁屏或远程桌面断开后的画面。跟随模式会检查窗口状态及部分遮挡情形，但不能检测所有遮挡。应用布局、显示分辨率或缩放变化后，请重新框选。

OCR 仍可能误读模糊、特殊字体或非常细小的数字。正式监控前应在实际显示条件下试识别。程序会跳过检测到的格式异常、识别冲突或明显遗漏，但不保证发现所有误识别。

## 测试

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\test.ps1
```

测试覆盖数值解析、阈值边界、连续命中、冷却、恢复布防、模拟 Bark 请求、系统通知设置保存及旧配置兼容、仅系统通知的界面保存、配置加密、实际 Windows OCR 及界面构建；使用 `tests/decimal-regression.png` 验证 `8.97` 小数点回归问题。

测试不真实发送 Bark 或 Windows 通知，也不播放声音。测试会尝试短暂显示一个测试窗口并截图；无法访问交互桌面的环境会明确记录跳过该项。系统通知实际显示效果需在交互桌面点击“测试系统通知”验证。OCR 结果也可能随安装的识别语言或 Windows 版本变化。
